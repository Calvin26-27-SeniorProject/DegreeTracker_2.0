Core Planner test cases

Every case the automated logic tests run, written out: the student’s courses on the left, what the tool concluded on the right. All 195 checks in these tests pass. Courses are made up except in “Reading Workday’s Excel export,” which uses a real, anonymized record.

How to read a case. The heading says what the case is meant to show. The right side lists the requirements that list one of the student’s courses or whose result differs from a student with no courses, plus the K&U total when any K&U hours count. A course that counts only because of an assumption says so in italics. “Then add” continues the same student with more courses. Statuses: Complete done; Minimum met K&U minimum met, with room for more hours; Not yet not done.

If a result looks wrong, note the case’s heading or the file and line under it.
